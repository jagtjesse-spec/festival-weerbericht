# Hullabaloo Weerwacht

Een weerpagina voor Hullabaloo 2026 — 5 en 6 september, Stadspark Groningen.

Eén statische HTML-pagina, geen build, geen dependencies. Alles zit in `index.html`.

## Live bekijken

De pagina staat live op <https://jagtjesse-spec.github.io/festival-weerbericht/>.

## Lokaal bekijken

Open `index.html` in je browser. Meer is er niet nodig.

## Bronnen

Weeronline, Weerplaza, Meteoblue, Weersvoorspelling.nl en Weer1.

Dit is een eigen weerpagina — geen officiële informatie van de festivalorganisatie.
